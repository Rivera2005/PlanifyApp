# 📋 Planify

Planify es una aplicación de lista de tareas (**To-Do App**) diseñada para ayudarte a organizar tu día de manera simple, rápida y efectiva.  
Con una interfaz intuitiva y herramientas flexibles, podrás gestionar tus pendientes y mantener el control de tu tiempo.  

---

## ✨ Funcionalidades

- ✅ **Crear tareas**: agrega fácilmente tus pendientes con título y descripción.  
- ✏️ **Editar tareas**: actualiza tus tareas cuando lo necesites.  
- ✔️ **Marcar como completadas**: mantén el control tachando lo que ya realizaste.  
- 📅 **Asignar fechas**: organiza tus tareas según el día que quieras.  
- 🔎 **Filtros personalizados**: crea tus propios filtros para visualizar tareas de acuerdo a tus necesidades (ej. por fecha, estado, prioridad, etc.).
